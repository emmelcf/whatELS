# Systemic Behavioral & Workflow Persistence Protocol

Whenever the user establishes a behavioral constraint, operational agreement, workflow protocol, or communication standard:

## 1. Immediate Persistence to Workspace Rules
- Do not keep the correction ephemeral in chat memory.
- Immediately record the agreed-upon standard in `.agents/rules/` under a descriptive filename.

## 2. Version Control Integration
- Stage and commit the rule to git so it permanently tracks with the codebase across machines, branches, and future chat sessions.

## 3. Explicit User Confirmation
- Explicitly notify the user which rule was codified, the file path where it was saved, and how it will govern future behavior.
